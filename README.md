# Gestão de Brinquedos

Esse projeto é sobre o gerenciamento de brinquedos de uma loja. Para isso, temos as opções cadastrar, editar e excluir brinquedos cadastrados.

Para adicionar a tabela de brinquedos no banco de dados, basta copiar o db.sql e colar no banco de dados. A partir disso, use o inserts.sql para saber o padrão de como os dados serão colocados na tabela.

## Cadastro

Para cadastrar o brinquedo, basta preencher os dados de forma correta na aba principal do site. Em seguida, aperte Cadastrar Brinquedo

## Edição

Para editar o brinquedo cadastrado, clique em Editar na linha do brinquedo na tabela, e será direcionado para o site de edição. No site, preencha as edições necessários de forma correta e aperte em Salvar Alterações.

## Exclusão

Para excluir o brinquedo, basta clicar em Excluir na linha do brinquedo, e em seguida ele vai ser excluido.
